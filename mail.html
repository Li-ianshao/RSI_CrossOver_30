版本更新說明：由於 Yahoo Finance 一些配息資訊不夠即時，改為由 Nasdaq 官網 API 讀取。

  • 選股原則：候選股票包括：(1) S&P500 成分股，(2) 股利貴族 Dividend Aristocrats (AR) 成分股，(3) 非 S&P500/AR 成分股，但是具有高殖利率的股票。
  • 股票代碼後面有 /SNP 標記者屬於 S&P500 成分股，標記有 /AR 標記者屬於 Dividend Aristocrats 股票。
  • 欄位"配息日"是指當天配息，如果在配息日買進，無法收到配息，亦即，如果想要參加配息，必須在配息日前一天以前買進。
  • 欄位"配息"是指當次每股配息金額，如果該股票是每季配息，配息就是當季所獲得的金額。
  • 欄位"殖利率"是根據過去一年所有的股息總額，除以當天收盤價計算。
  • 後續"填息次數"，"填息次數"，"填息率"等相關資訊是依據過去 25 年各檔股票配息填息資料計算所得。有些股票上市不滿 25年 則以既有資料計算。
  • "跌幅"欄位是指最近兩個月最高收盤價與最近收盤價之間的跌幅，如果顯示為 0.0% 表示今日收盤價是最近兩個月內新高點。
  • RSI 是 Relative Strength Index，技術分析常用的指標之一，一般來說，RSI 小於 30 表示該檔股票超賣 (oversold)。
  • 注意：雖然大多數股票都是每季配息，但是也有些股票是每半年配息，或者每月配息，殖利率是指每年配息。相關配息資料可以透過 這裡查詢。
  • 所有交易相關資料係由 Yahoo Finance 與 Nasdaq 官方 API 提供，請注意該公司免責聲明。
